# 1. Intro To ML and Data Science

Start here. This module is a short orientation, not a technical deep-dive — it exists
to explain what the course covers, in what order, and why, before Module 2 starts on
Python fundamentals.

## Contents

- **`1. Welcome and Orientation.ipynb`** — what ML and data science are, the full
  course roadmap and module dependencies, an environment check, and one small
  end-to-end example (fertility vs. child mortality on the Gapminder dataset) that
  previews the load → visualize → summarize pattern used throughout the rest of the
  course.
- **`Course Introduction.pptx`** / **`Overview.pptx`** — the slide-deck version of the
  same orientation, for instructor-led sessions.

## Before you continue

Make sure your environment is set up:

```bash
poetry install
poetry run jupyter notebook
```

Then open `1. Welcome and Orientation.ipynb` and run the environment-check cell —
it will tell you immediately if anything is missing before you invest time in the
rest of the course.
