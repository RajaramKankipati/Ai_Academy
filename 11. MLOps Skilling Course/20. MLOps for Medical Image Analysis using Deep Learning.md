# MLOps for Medical Image Analysis using Deep Learning

## Overview

You will train a small neural network that flags breast-mass samples as possibly malignant, from measurements taken from microscope images. Then you add the safeguards a **clinical** model needs: a decision threshold chosen so no malignant case is missed, a physician-review band for uncertain cases, a package that carries its preprocessing and threshold with it, serving code tested locally, and monitoring that works before biopsy results arrive.

Three things change when a wrong prediction can cost a diagnosis:

- **Errors are not symmetric.** Calling a malignant mass benign is far worse than an unnecessary follow-up biopsy. The threshold cannot stay at 0.5, and accuracy is the wrong yardstick.
- **The model does not decide; it triages.** It returns a recommendation **and** says when a physician must look.
- **Monitoring watches the input pipeline.** A new scanner or stain protocol shifts the measurements without any change to the model's code.

By the end, you will be able to:

- Split data three ways and choose the threshold on validation data, not test data.
- Train a Keras network with class weights and early stopping.
- Export a TensorFlow SavedModel together with its scaler, threshold and serving code.
- Test SageMaker's TensorFlow Serving handlers locally.
- Monitor leading indicators (flag rate, review share, feature drift) without labels.
- Deploy to a SageMaker endpoint.

**Prerequisites:** Python 3.11 and Sessions 8 and 19. Steps 1–8 run locally (TensorFlow is a ~600 MB install). **Step 9 needs an AWS account** with SageMaker, as in Session 8; the endpoint bills per hour.

**Dataset:** [UCI Breast Cancer Wisconsin (Diagnostic)](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic), 569 fine-needle aspirate samples, labelled malignant or benign. It is downloaded automatically by the code.

**This is a teaching exercise, not a medical device.** Anything used for real diagnosis needs regulatory approval, clinical validation and audits far beyond a lab.

### Where are the images?

Each sample's microscope slide was photographed, the cell nuclei were outlined in the image, and ten properties were measured on every nucleus (radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, fractal dimension). Each property is summarised three ways across the nuclei: mean (`radius1`), standard error (`radius2`) and "worst", the mean of the three largest values (`radius3`). 10 × 3 = 30 columns.

So this **is** medical image analysis, with the image-processing stage already done. That two-stage design (an image feature-extraction service, then a diagnostic model) is common in production:

| | Raw-pixel deep model | Features + diagnostic model |
| --- | --- | --- |
| Data to store and version | Terabytes of images | A few kilobytes (fits in DVC, Session 2) |
| "Why malignant?" | A heat map | "Worst concave points 3 standard deviations above normal" (SHAP, Session 22) |
| A new scanner changes images | Hard to say what moved | You see which **measurement** shifted (Step 7) |

This lab builds and operates the second stage. The first stage's output is its input contract, and that contract is what the monitoring watches.

## Step 3: Three splits (src/data.py)

```python
"""Load the Wisconsin Diagnostic Breast Cancer data and split it three ways."""
from sklearn.model_selection import train_test_split


def load_splits():
    from ucimlrepo import fetch_ucirepo

    ds = fetch_ucirepo(id=17)
    X = ds.data.features
    y = (ds.data.targets["Diagnosis"] == "M").astype(int).values   # 1 = malignant
    X_train, X_hold, y_train, y_hold = train_test_split(
        X, y, test_size=0.3, random_state=42, stratify=y)
    X_val, X_test, y_val, y_test = train_test_split(
        X_hold, y_hold, test_size=0.5, random_state=42, stratify=y_hold)
    return X_train, X_val, X_test, y_train, y_val, y_test
```

| Split | Rows | Used for |
| --- | --- | --- |
| train | 398 | Fitting the scaler and the network |
| validation | 85 | Early stopping **and choosing the threshold** |
| test | 86 | One final, honest measurement. Nothing is chosen from it |

Choosing the threshold on the test set would leak test information into the model, and the test score would no longer be an honest estimate.

37% of these samples are malignant. That is far higher than in population screening, because these masses were already suspicious enough to biopsy. This model is a **triage aid for referred cases**, not a screening tool. Deployed on a screening population, its flag rate would be far off, and the monitoring in Step 7 should, rightly, alarm.

## Step 4: Train, choose the threshold, export (src/train.py)

```python
"""Train the network, pick the operating threshold on VALIDATION data, test once, export."""
import json
import os
import shutil
import tarfile

import keras
import numpy as np
from sklearn.metrics import confusion_matrix, roc_auc_score
from sklearn.preprocessing import StandardScaler
from sklearn.utils.class_weight import compute_class_weight

from src.data import load_splits

REVIEW_UPPER = 0.60   # flagged cases below this probability also go to a physician

keras.utils.set_random_seed(42)
X_train, X_val, X_test, y_train, y_val, y_test = load_splits()
for name, y in [("train", y_train), ("val", y_val), ("test", y_test)]:
    print(f"{name:<5} {len(y):>3} samples, {y.mean():.1%} malignant")

scaler = StandardScaler().fit(X_train)                       # statistics from train only
Xtr, Xva, Xte = (scaler.transform(X) for X in (X_train, X_val, X_test))

model = keras.Sequential([
    keras.Input(shape=(30,), name="features"),
    keras.layers.Dense(32, activation="relu"),
    keras.layers.Dropout(0.3),
    keras.layers.Dense(16, activation="relu"),
    keras.layers.Dense(1, activation="sigmoid", name="malignancy_probability"),
])
model.compile(optimizer=keras.optimizers.Adam(1e-3), loss="binary_crossentropy",
              metrics=[keras.metrics.AUC(name="auc"), keras.metrics.Recall(name="recall")])
print(f"trainable parameters: {model.count_params()}")

weights = compute_class_weight("balanced", classes=np.array([0, 1]), y=y_train)
history = model.fit(
    Xtr, y_train, validation_data=(Xva, y_val), epochs=300, batch_size=32, verbose=0,
    class_weight={0: weights[0], 1: weights[1]},
    callbacks=[keras.callbacks.EarlyStopping(monitor="val_auc", mode="max", patience=20,
                                             restore_best_weights=True)],
)
best = int(np.argmax(history.history["val_auc"]))
print(f"stopped after {len(history.history['loss'])} epochs; best epoch {best + 1}, "
      f"val AUC {history.history['val_auc'][best]:.4f}")

# Threshold: the HIGHEST value that still catches every malignant case in VALIDATION.
p_val = model.predict(Xva, verbose=0).ravel()
threshold = float(np.floor(p_val[y_val == 1].min() * 100) / 100)
review_band = (threshold, REVIEW_UPPER)
print(f"\noperating threshold (chosen on validation): {threshold:.2f}")
print(f"physician review band: {review_band[0]:.2f}-{review_band[1]:.2f}")

p_test = model.predict(Xte, verbose=0).ravel()
print(f"test AUC: {roc_auc_score(y_test, p_test):.4f}")
for name, t in [("default", 0.5), ("operating", threshold)]:
    tn, fp, fn, tp = confusion_matrix(y_test, (p_test >= t).astype(int)).ravel()
    print(f"  {name:<9} t={t:.2f}:  TN {tn}  FP {fp}  FN {fn}  TP {tp}  recall {tp / (tp + fn):.3f}")
in_band = ((p_test >= review_band[0]) & (p_test <= review_band[1])).mean()
print(f"test cases sent to physician review: {in_band:.1%}")

# Export: SavedModel for TensorFlow Serving, plus everything serving needs, in one tarball.
shutil.rmtree("export", ignore_errors=True)
model.export("export/model/1")                     # TF Serving needs a numbered version folder
config = {"threshold": threshold, "review_band": list(review_band),
          "feature_order": list(X_train.columns),
          "scaler_mean": scaler.mean_.tolist(), "scaler_scale": scaler.scale_.tolist()}
json.dump(config, open("export/model/1/serving_config.json", "w"), indent=2)
os.makedirs("export/code")
shutil.copy("serving/inference.py", "export/code/inference.py")
with tarfile.open("model.tar.gz", "w:gz") as tar:
    tar.add("export/model", arcname="model")
    tar.add("export/code", arcname="code")
np.save("export/reference_probs.npy", model.predict(Xtr, verbose=0).ravel())
print(f"\nmodel.tar.gz: {os.path.getsize('model.tar.gz'):,} bytes")
```

`train.py` copies `serving/inference.py` into the package, so create that file (Step 5) **before** running it.

What each part does:

- **`StandardScaler` fitted on train only.** Features range from about 0.05 (concave points) to over 1,000 (area); unscaled, the large ones would dominate the network. The scaler's means and scales become **part of the model**.
- **A deliberately small network** (1,537 parameters for 398 samples). `Dropout(0.3)` and **early stopping** with `restore_best_weights=True` keep it from memorising: training stops when validation AUC has not improved for 20 epochs, and the best epoch's weights are kept.
- **`class_weight`** makes each malignant case count more, so the network does not ignore the smaller class.
- **The threshold** is the highest value that still flags **every** malignant case in validation. That is the policy: catch them all, then minimise false alarms.
- **The review band** runs from the threshold to 0.60: everything flagged **only** because of the lowered threshold also goes to a physician.
- **One package (`model.tar.gz`)** holds the SavedModel in `model/1/` (TensorFlow Serving finds models by numbered version folder), the scaler statistics, threshold and feature order in `serving_config.json`, and the serving code in `code/inference.py`. They are versioned together, so the clinical policy cannot change silently without a new package.

How to read it:

- **At the default 0.5, one malignant case is missed** (`FN 1`). That patient goes home. Overall accuracy would still be 98.8%.
- **At 0.05, nothing is missed**, at the cost of 6 healthy patients sent for a follow-up test. With any sensible cost ratio (a missed cancer is far worse than an extra biopsy), that trade is right. The default 0.5 silently assumes both errors cost the same.
- **The threshold was chosen on validation and confirmed on test.** Recall 1.000 on test is evidence it generalises, though with only 32 malignant test cases one miss would mean 0.969.
- **8% of cases go to physician review.** That is a staffing number: at 200 samples a day, 16 manual reviews.

## Step 5: The serving code (serving/inference.py)

SageMaker's TensorFlow Serving container runs `code/inference.py` around the model: `input_handler` turns the request into TensorFlow Serving's format, and `output_handler` turns the model's output into your response.

```python
"""Pre- and post-processing for SageMaker's TensorFlow Serving container (standard library only)."""
import json
import os

CONFIG_PATH = os.environ.get("SERVING_CONFIG", "/opt/ml/model/model/1/serving_config.json")
_config = None


def config():
    global _config
    if _config is None:
        with open(CONFIG_PATH) as f:
            _config = json.load(f)
    return _config


def input_handler(data, context):
    """JSON with 30 NAMED features in -> scaled numbers for TensorFlow Serving."""
    cfg = config()
    payload = json.loads(data.read().decode("utf-8"))
    missing = [f for f in cfg["feature_order"] if f not in payload]
    if missing:
        raise ValueError(f"missing features: {missing}")
    scaled = [(float(payload[f]) - mean) / scale
              for f, mean, scale in zip(cfg["feature_order"], cfg["scaler_mean"],
                                        cfg["scaler_scale"])]
    return json.dumps({"instances": [scaled]})


def output_handler(response, context):
    """TensorFlow Serving's probability in -> recommendation plus a review flag out."""
    if response.status_code != 200:
        raise ValueError(response.content.decode("utf-8"))
    cfg = config()
    prob = float(json.loads(response.content)["predictions"][0][0])
    low, high = cfg["review_band"]
    result = {
        "malignancy_probability": round(prob, 4),
        "recommendation": "malignant" if prob >= cfg["threshold"] else "benign",
        "requires_physician_review": bool(low <= prob <= high),
        "threshold": cfg["threshold"],
    }
    return json.dumps(result), "application/json"
```

- **Features are taken by name**, in the training order. A caller who sends them in another order still gets the right answer; a caller who leaves one out gets an error naming it, instead of a plausible wrong probability.
- **The scaling uses the stored training statistics.** Forget it and the network sees raw numbers it has never seen, and answers confidently and wrongly, with no error.
- **Only the standard library**, so the container needs no extra packages.
- **Every response carries the threshold**, so an audit can reconstruct why a case was flagged.

## Step 6: Test the serving path locally (tests/test\_serving.py)

These tests do what TensorFlow Serving does: call `input_handler`, run the exported SavedModel's `serving_default` signature, then call `output_handler`. A packaging or handler bug shows up here in seconds, not after a 7-minute deploy.

```python
"""Run the SageMaker handlers around the exported SavedModel, as TensorFlow Serving would."""
import io
import json
import os

import numpy as np
import pytest
import tensorflow as tf

os.environ["SERVING_CONFIG"] = "export/model/1/serving_config.json"
from serving import inference  # noqa: E402

from src.data import load_splits  # noqa: E402

MODEL = tf.saved_model.load("export/model/1").signatures["serving_default"]
_, _, X_test, _, _, y_test = load_splits()


class FakeResponse:                       # what TensorFlow Serving hands to output_handler
    def __init__(self, body):
        self.status_code, self.content = 200, json.dumps(body).encode()


def serve(features):
    request = inference.input_handler(io.BytesIO(json.dumps(features).encode()), None)
    instances = np.array(json.loads(request)["instances"], dtype="float32")
    probs = MODEL(features=tf.constant(instances))["output_0"].numpy().tolist()
    body, content_type = inference.output_handler(FakeResponse({"predictions": probs}), None)
    return json.loads(body)


def test_every_malignant_test_case_is_flagged():
    results = [serve(row) for row in X_test.to_dict(orient="records")]
    flagged = np.array([r["recommendation"] == "malignant" for r in results])
    assert flagged[y_test == 1].all()


def test_feature_order_in_the_request_does_not_matter():
    row = X_test.iloc[0].to_dict()
    assert serve(row) == serve(dict(reversed(list(row.items()))))


def test_missing_feature_is_rejected_by_name():
    row = X_test.iloc[0].to_dict()
    del row["concave_points3"]
    with pytest.raises(ValueError, match="concave_points3"):
        serve(row)


def test_uncertain_cases_go_to_review():
    results = [serve(row) for row in X_test.to_dict(orient="records")]
    low, high = inference.config()["review_band"]
    for r in results:
        assert r["requires_physician_review"] == (low <= r["malignancy_probability"] <= high)
```

## Step 7: Monitor before the labels arrive (src/monitor.py)

Biopsy results come back days or weeks after a prediction. The false-negative rate, the number that matters most, cannot be computed until then. Meanwhile, watch **leading indicators**.

```python
"""Leading indicators for a batch of cases, before biopsy results (labels) arrive.

Usage: python -m src.monitor normal | new_scanner
"""
import json
import sys

import numpy as np
import tensorflow as tf

from src.data import load_splits

scenario = sys.argv[1]
cfg = json.load(open("export/model/1/serving_config.json"))
model = tf.saved_model.load("export/model/1").signatures["serving_default"]
X_train, _, X_test, _, _, _ = load_splits()

batch = X_test.copy()
if scenario == "new_scanner":            # a new microscope camera renders texture differently
    for col in ["texture1", "texture2", "texture3"]:
        batch[col] = batch[col] * 1.25


def probabilities(frame):
    scaled = (frame[cfg["feature_order"]].values - cfg["scaler_mean"]) / cfg["scaler_scale"]
    return model(features=tf.constant(scaled, dtype=tf.float32))["output_0"].numpy().ravel()


def psi(reference, current, bins=5):
    edges = np.percentile(reference, np.linspace(0, 100, bins + 1))
    edges[0], edges[-1] = -np.inf, np.inf
    ref = np.histogram(reference, edges)[0] / len(reference) + 1e-6
    cur = np.histogram(current, edges)[0] / len(current) + 1e-6
    return float(((cur - ref) * np.log(cur / ref)).sum())


reference = np.load("export/reference_probs.npy")
probs = probabilities(batch)
low, high = cfg["review_band"]
report = {
    "flag_rate": round(float((probs >= cfg["threshold"]).mean()), 3),
    "flag_rate_baseline": round(float((reference >= cfg["threshold"]).mean()), 3),
    "review_share": round(float(((probs >= low) & (probs <= high)).mean()), 3),
    "psi": {col: round(psi(X_train[col], batch[col]), 3)
            for col in ["concave_points3", "radius3", "texture1", "texture3"]},
}
alerts = [f"PSI {c} {v}" for c, v in report["psi"].items() if v > 0.25]
if abs(report["flag_rate"] - report["flag_rate_baseline"]) > 0.10:
    alerts.append("flag rate moved more than 10 points")
if report["review_share"] > 0.20:
    alerts.append("more than 20% of cases need review")
report["alerts"] = alerts
print(json.dumps(report, indent=2))
```

| Indicator | Question it answers | Here |
| --- | --- | --- |
| `flag_rate` vs baseline | Did the case mix or the imaging front-end change? | Up 10 points with no clinical reason |
| `review_share` | Is the model costing physicians more time than it saves? | Doubled, from 8% to 16% |
| PSI per feature | **Which** measurement moved? | Only texture: the scanner, not the patients |

Only texture moved; size and shape did not. That points at the imaging front-end (a new camera or stain), not a change in the patient population. The fix is to recalibrate the feature extractor, **not** to retrain the model on the shifted measurements, which would teach it that the miscalibration is normal.

### src/predict.py

```python
"""Send three real test cases to the endpoint: clearly benign, clearly malignant, borderline."""
import json

import boto3

from src.config import ENDPOINT_NAME, REGION
from src.data import load_splits

_, _, X_test, _, _, y_test = load_splits()
runtime = boto3.client("sagemaker-runtime", region_name=REGION)


def score(row):
    body = runtime.invoke_endpoint(EndpointName=ENDPOINT_NAME, ContentType="application/json",
                                   Body=json.dumps(row))["Body"].read()
    return json.loads(body)


results = [(score(row), label) for row, label in zip(X_test.to_dict(orient="records"), y_test)]
results.sort(key=lambda r: r[0]["malignancy_probability"])
borderline = min(results, key=lambda r: abs(r[0]["malignancy_probability"] - 0.3))
for name, (result, label) in [("lowest", results[0]), ("highest", results[-1]),
                              ("borderline", borderline)]:
    print(f"{name:<11} truth={'malignant' if label else 'benign':<9} {result}")
```

## Common errors and fixes

| Error | Cause | Fix |
| --- | --- | --- |
| `KeyError: 4` (or another number) in `model.fit` | Labels passed as a pandas Series with a shuffled index | Pass NumPy arrays, as `load_splits` does with `.values` |
| `FileNotFoundError: serving/inference.py` in `train.py` | Serving code not created yet | Create `serving/inference.py` (Step 5) first |
| Training runs all 300 epochs | Early stopping not watching the right metric | `monitor="val_auc", mode="max"` |
| Great test score, worse in production | Threshold chosen on the test set | Choose it on validation; test once |
| Endpoint returns `Servable not found` | Wrong layout inside `model.tar.gz` | Must be `model/1/saved_model.pb`; check with `tar tzf` |
| Confident but wrong predictions, no error | Raw features sent to the network without scaling | Scale with the stored statistics in `input_handler` |
| `ValueError: missing features: [...]` | Request lacks a feature | Send all 30 features by name |
| Updated `model.tar.gz` in S3, endpoint unchanged | A running endpoint does not reload from S3 | Redeploy (new endpoint config) |
