# E2E Pipeline to Deploy and Monitor ML and LLM Apps on GCP

## Overview

You will ship a **hybrid** app to Google Cloud. A classic scikit-learn spam classifier makes the decision, and **Gemini** (Google's LLM, through Vertex AI) turns that decision into one plain-language sentence for the user. Then you monitor **both halves**, because they fail in different ways:

| Part | How it fails | What to watch |
| --- | --- | --- |
| Classifier | Slowly and silently: spammers change their wording, accuracy erodes over weeks | Spam rate, score distribution (PSI), share of unsure scores |
| LLM | Suddenly and loudly: quota limits, safety blocks, slow or empty answers | Error rate, latency, tokens used |

```text
SMS text ──► classifier (TF-IDF + logistic regression) ──► label + score
                                                              │  only if asked, or if unsure
                                                              ▼
                       explanation ◄── Gemini: "explain this verdict in one sentence"
```

By the end, you will be able to:

- Build a service where an LLM explains, but never decides, and never takes the service down.
- Ground the LLM's answer in the model's real evidence, so it cannot invent reasons.
- Log one structured record per request that covers both the ML and the LLM part.
- Deploy the service to **Cloud Run** with access to Gemini.
- Compare live traffic with a training baseline and push the results to **Cloud Monitoring**.

**Prerequisites:** Python 3.11, and Sessions 6 and 7 (FastAPI, Docker). Steps 1–8 are free and run locally without any Google account; the LLM is switched off and the service falls back to a template. **Steps 9–12 need a Google Cloud project with billing enabled** and the [`gcloud` CLI](https://cloud.google.com/sdk/docs/install). Gemini is billed per token and Cloud Run per request, so idle cost is close to zero.

**Dataset:** [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection), 5,574 real English text messages labelled `ham` (normal) or `spam`. Spam has human-readable signals ("FREE", "claim now", short codes), which lets you check whether the LLM's explanations are honest. This dataset is **not** available through `ucimlrepo`, so the code downloads the ZIP file directly.

### src/data.py

```python
"""Download the UCI SMS Spam Collection (it is not available through ucimlrepo)."""
import io
import urllib.request
import zipfile

import pandas as pd

URL = "https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip"


def load_sms():
    with urllib.request.urlopen(URL) as resp:
        archive = zipfile.ZipFile(io.BytesIO(resp.read()))
    with archive.open("SMSSpamCollection") as f:
        df = pd.read_csv(f, sep="\t", header=None, names=["label", "message"],
                         quoting=3, encoding="utf-8")
    return df
```

The file is tab-separated with no header. `quoting=3` tells pandas not to treat quote marks inside messages as special.

### src/train.py

```python
"""Train the spam classifier and save it with a monitoring baseline."""
import json

import joblib
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, roc_auc_score
from sklearn.model_selection import train_test_split
from sklearn.pipeline import Pipeline

from src.data import load_sms

df = load_sms()
print(f"{len(df)} messages: {df['label'].value_counts().to_dict()}, "
      f"spam rate {(df['label'] == 'spam').mean():.4f}")
print(f"duplicate messages: {df['message'].duplicated().sum()}")

df = df.drop_duplicates("message")          # keep copies out of both train and test
X_tr, X_te, y_tr, y_te = train_test_split(
    df["message"], (df["label"] == "spam").astype(int),
    test_size=0.2, stratify=df["label"], random_state=42,
)
pipe = Pipeline([
    ("tfidf", TfidfVectorizer(sublinear_tf=True, ngram_range=(1, 2), min_df=2)),
    ("clf", LogisticRegression(max_iter=1000, class_weight="balanced")),
])
pipe.fit(X_tr, y_tr)

proba = pipe.predict_proba(X_te)[:, 1]
print(classification_report(y_te, (proba > 0.5).astype(int),
                            target_names=["ham", "spam"], digits=3))
print(f"ROC AUC: {roc_auc_score(y_te, proba):.4f}")

train_scores = pipe.predict_proba(X_tr)[:, 1]
baseline = {
    "spam_rate": round(float(y_tr.mean()), 4),
    "mean_msg_len": round(float(X_tr.str.len().mean()), 1),
    "score_histogram": np.histogram(train_scores, bins=10, range=(0, 1))[0].tolist(),
}
joblib.dump(pipe, "model/spam.joblib")
with open("model/baseline.json", "w") as f:
    json.dump(baseline, f, indent=2)
print(json.dumps(baseline))
```

- **403 duplicate messages.** The same promotional text is often sent many times. Left in, copies would land in both train and test, and the test score would be inflated. We remove them before splitting (the lesson from Session 11).
- **Accuracy 0.98 says little.** Most messages are ham. Watch the **spam row**: recall 0.916 means 8% of spam gets through. That number drops first when spammers change their wording.
- **TF-IDF + logistic regression** is plain on purpose: it trains in seconds, works very well on short texts, and every word has a coefficient we can show to the LLM as **evidence**.
- **The baseline.** Drift detection is a comparison, so we save what normal looked like at training time: the spam rate, the average message length, and a 10-bin histogram of scores. It is far easier to record this now than to reconstruct it from production later.

## Step 5: The LLM layer (app/explain.py)

```python
"""Turn a classifier verdict into one plain-language sentence with Gemini."""
import os

import numpy as np

USE_LLM = os.environ.get("USE_LLM", "0") == "1"
PROJECT = os.environ.get("GOOGLE_CLOUD_PROJECT", "")
REGION = os.environ.get("GOOGLE_CLOUD_REGION", "us-central1")
LLM_MODEL = os.environ.get("LLM_MODEL", "gemini-2.5-flash")

PROMPT = """You are explaining an automated spam filter to a non-technical user.

Message: "{msg}"
Filter verdict: {label} (confidence {score:.2f})
Terms that most influenced the verdict: {evidence}

In ONE sentence, explain the verdict in plain language, referring only to the
evidence listed. Do not re-judge the message yourself. If the confidence is
below 0.65, say the filter was unsure."""

_client = None


def top_evidence(pipe, text, k=5):
    """The k terms in this message that pushed the score most towards spam."""
    vec, clf = pipe.named_steps["tfidf"], pipe.named_steps["clf"]
    contrib = vec.transform([text]).multiply(clf.coef_[0]).toarray()[0]
    names = vec.get_feature_names_out()
    idx = np.argsort(contrib)[-k:][::-1]
    return [(str(names[i]), round(float(contrib[i]), 3)) for i in idx if contrib[i] > 0]


def call_llm(prompt):
    """Return (text, tokens). Imported lazily so the app runs without Google libraries set up."""
    global _client
    from google import genai
    from google.genai import types

    if _client is None:
        _client = genai.Client(vertexai=True, project=PROJECT, location=REGION)
    resp = _client.models.generate_content(
        model=LLM_MODEL, contents=prompt,
        config=types.GenerateContentConfig(temperature=0.2, max_output_tokens=120),
    )
    return (resp.text or "").strip(), resp.usage_metadata.total_token_count or 0


def explain(pipe, msg, label, score):
    """Return (explanation, status, tokens). Never raises: the verdict must always get out."""
    fallback = f"Classified as {label} (confidence {score:.2f})."
    if not USE_LLM:
        return fallback, "disabled", 0
    evidence = top_evidence(pipe, msg)
    try:
        text, tokens = call_llm(PROMPT.format(msg=msg, label=label, score=score,
                                              evidence=evidence))
    except Exception as exc:                 # quota (429), permissions, timeouts, ...
        return fallback, type(exc).__name__, 0
    if not text:                             # e.g. blocked by a safety filter
        return fallback, "empty", tokens
    return text, "ok", tokens
```

What each part does:

- **`top_evidence`** multiplies each word's TF-IDF weight in this message by the model's coefficient for that word. The biggest positive products are the words that pushed **this** message towards spam.
- **The prompt gives Gemini the evidence and forbids it to re-judge.** Without evidence, an LLM produces a plausible-sounding reason that may have nothing to do with the real decision. If an explanation mentions something not in the evidence list (e.g. "the sender is unknown", a fact never provided), the LLM is making it up; tighten the prompt.
- **`temperature=0.2`** keeps answers consistent; **`max_output_tokens=120`** caps cost per call.
- **`explain` never raises.** Every failure (quota, permissions, timeout) returns the template sentence plus a **status** saying what went wrong. The verdict is the product; the explanation is extra, and extra must never take the service down.
- **An empty answer is its own status.** If Gemini's safety filter blocks a message (spam is exactly the kind of text filters are tuned for), the call **succeeds** with empty text. Without this check, the failure would be invisible.
- **`USE_LLM`** switches Gemini on. It is off by default, so everything up to Step 8 runs with no Google account.
- **`LLM_MODEL`** is a setting, not code. Gemini model names change; check **Vertex AI → Model Garden** for the current ones and set the variable.

## Step 6: The service (app/main.py)

```python
"""Spam classifier + LLM explanation service, with one structured log line per request."""
import json
import os
import time
import uuid

import joblib
from fastapi import FastAPI
from pydantic import BaseModel, Field

from app import explain as llm

MODEL_PATH = os.environ.get("MODEL_PATH", "model/spam.joblib")
PIPE = joblib.load(MODEL_PATH)
AMBIGUOUS = (0.35, 0.65)

app = FastAPI(title="SMS Spam Service")


class Message(BaseModel):
    message: str = Field(..., min_length=1, max_length=1000)
    explain: bool = False


@app.get("/health")
def health():
    return {"status": "ok", "llm": llm.LLM_MODEL if llm.USE_LLM else "disabled"}


@app.post("/classify")
def classify(req: Message):
    rec = {"request_id": uuid.uuid4().hex[:8], "msg_len": len(req.message)}

    t0 = time.perf_counter()
    score = float(PIPE.predict_proba([req.message])[0, 1])
    rec["clf_ms"] = round((time.perf_counter() - t0) * 1000, 1)
    rec["score"] = round(score, 4)
    rec["label"] = "spam" if score > 0.5 else "ham"

    # Call the slow LLM only when someone asked, or when the model is unsure.
    wants_llm = req.explain or AMBIGUOUS[0] <= score <= AMBIGUOUS[1]
    t1 = time.perf_counter()
    if wants_llm:
        text, status, tokens = llm.explain(PIPE, req.message, rec["label"], score)
    else:
        text, status, tokens = None, "skipped", 0
    rec["llm_ms"] = round((time.perf_counter() - t1) * 1000, 1)
    rec.update(llm_status=status, llm_tokens=tokens)

    print(json.dumps({"severity": "INFO", "message": "classify", **rec}), flush=True)
    return {**rec, "explanation": text}
```

- **The LLM is called only when it adds value**: when the user asks (`explain: true`) or when the classifier is unsure (score between 0.35 and 0.65). The classifier answers in about a millisecond; an LLM call takes hundreds of milliseconds to seconds. Calling Gemini on every message would make the whole service as slow and as expensive as the LLM.
- **One log line per request, as JSON.** Cloud Run sends anything printed to Cloud Logging, and a JSON line becomes a searchable record with fields (`llm_status`, `score`, ...). Both halves of the request are in **one** record, so you can join them later: "show me the slow requests that were also ambiguous".

## Step 7: Test the service with a fake LLM (tests/test\_service.py)

The LLM is replaced with small fake functions (`monkeypatch`), so we can test success, failure and empty answers without any network call or cost.

```python
from fastapi.testclient import TestClient

from app import explain as llm
from app.main import app

client = TestClient(app)
SPAM = "URGENT! You have won a 1 week FREE membership. Text CLAIM to 81010 now"
HAM = "Hey, are we still on for lunch tomorrow at 1?"


def test_obvious_spam_and_ham():
    assert client.post("/classify", json={"message": SPAM}).json()["label"] == "spam"
    assert client.post("/classify", json={"message": HAM}).json()["label"] == "ham"


def test_llm_is_skipped_for_confident_scores_unless_asked():
    body = client.post("/classify", json={"message": HAM}).json()
    assert body["llm_status"] == "skipped" and body["explanation"] is None


def test_evidence_contains_spam_words():
    from app.main import PIPE
    words = [w for w, _ in llm.top_evidence(PIPE, SPAM)]
    assert "claim" in words or "free" in words


def test_llm_answer_is_used(monkeypatch):
    monkeypatch.setattr(llm, "USE_LLM", True)
    monkeypatch.setattr(llm, "call_llm", lambda prompt: ("Flagged for 'free' and 'claim'.", 42))
    body = client.post("/classify", json={"message": SPAM, "explain": True}).json()
    assert body["llm_status"] == "ok"
    assert body["llm_tokens"] == 42
    assert body["explanation"] == "Flagged for 'free' and 'claim'."


def test_llm_failure_falls_back_and_never_breaks_the_verdict(monkeypatch):
    def quota_exceeded(prompt):
        raise RuntimeError("429 RESOURCE_EXHAUSTED")

    monkeypatch.setattr(llm, "USE_LLM", True)
    monkeypatch.setattr(llm, "call_llm", quota_exceeded)
    resp = client.post("/classify", json={"message": SPAM, "explain": True})
    assert resp.status_code == 200
    body = resp.json()
    assert body["label"] == "spam"
    assert body["llm_status"] == "RuntimeError"
    assert body["explanation"].startswith("Classified as spam")


def test_empty_llm_answer_is_reported(monkeypatch):
    monkeypatch.setattr(llm, "USE_LLM", True)
    monkeypatch.setattr(llm, "call_llm", lambda prompt: ("", 7))
    body = client.post("/classify", json={"message": SPAM, "explain": True}).json()
    assert body["llm_status"] == "empty"


def test_empty_message_is_rejected():
    assert client.post("/classify", json={"message": ""}).status_code == 422
```

## Step 8: Simulate traffic and monitor it locally

### src/traffic.py

A spam campaign hits your users: 30% of messages are spam instead of the usual 13%. Every tenth request asks for an explanation.

```python
"""Send a spam-heavy burst of real messages to the service and save what came back.

Usage: python -m src.traffic http://localhost:8080
"""
import sys
import time

import pandas as pd
import requests

from src.data import load_sms

base = sys.argv[1].rstrip("/")
df = load_sms()
# A spam campaign: 30% spam instead of the usual 13%.
messages = (df[df.label == "spam"].message.sample(60, random_state=7).tolist()
            + df[df.label == "ham"].message.sample(140, random_state=7).tolist())

rows = []
for i, msg in enumerate(messages):
    t0 = time.perf_counter()
    body = requests.post(f"{base}/classify",
                         json={"message": msg, "explain": i % 10 == 0}, timeout=60).json()
    body["total_ms"] = round((time.perf_counter() - t0) * 1000, 1)
    rows.append(body)

live = pd.DataFrame(rows)
live.to_csv("live.csv", index=False)
print(f"sent {len(live)} requests -> live.csv")
```

### src/monitor.py

```python
"""Compare live traffic (live.csv) with the training baseline. Optionally push to Cloud Monitoring.

Usage: python -m src.monitor            print the report
       python -m src.monitor --push     also write the metrics to Cloud Monitoring
"""
import json
import sys
import time

import numpy as np
import pandas as pd


def psi(expected_counts, actual_scores):
    """Population Stability Index between a baseline histogram and live scores."""
    e = np.array(expected_counts) / sum(expected_counts)
    a = np.histogram(actual_scores, bins=10, range=(0, 1))[0] / len(actual_scores)
    e, a = np.clip(e, 1e-6, None), np.clip(a, 1e-6, None)
    return float(((a - e) * np.log(a / e)).sum())


baseline = json.load(open("model/baseline.json"))
live = pd.read_csv("live.csv")
called = live[~live.llm_status.isin(["skipped", "disabled"])]   # real LLM calls

metrics = {
    "latency_p50_ms": float(live.total_ms.quantile(0.50)),
    "latency_p95_ms": float(live.total_ms.quantile(0.95)),
    "spam_rate": float((live.label == "spam").mean()),
    "score_psi": psi(baseline["score_histogram"], live.score),
    "ambiguous_share": float(live.score.between(0.35, 0.65).mean()),
    "llm_error_rate": float((called.llm_status != "ok").mean()) if len(called) else 0.0,
}

print(f"requests              : {len(live)}  (LLM called for {len(called)})")
print(f"latency p50 / p95     : {metrics['latency_p50_ms']:.1f} / {metrics['latency_p95_ms']:.1f} ms")
print(f"classifier p95        : {live.clf_ms.quantile(0.95):.1f} ms")
if len(called):
    print(f"LLM p95 (when called) : {called.llm_ms.quantile(0.95):.1f} ms")
print(f"spam rate live / base : {metrics['spam_rate']:.3f} / {baseline['spam_rate']:.3f}")
print(f"mean length live/base : {live.msg_len.mean():.1f} / {baseline['mean_msg_len']:.1f}")
print(f"score PSI             : {metrics['score_psi']:.3f}")
print(f"ambiguous 0.35-0.65   : {metrics['ambiguous_share']:.1%}")
print(f"LLM status counts     : {live.llm_status.value_counts().to_dict()}")
alerts = {
    "score PSI above 0.25": metrics["score_psi"] > 0.25,
    "spam rate more than 2x baseline": metrics["spam_rate"] > 2 * baseline["spam_rate"],
    "more than 10% ambiguous scores": metrics["ambiguous_share"] > 0.10,
    "LLM error rate above 5%": metrics["llm_error_rate"] > 0.05,
}
fired = [name for name, hit in alerts.items() if hit]
print("ALERTS:", fired if fired else "none")

if "--push" in sys.argv:
    from google.cloud import monitoring_v3

    from app.explain import PROJECT

    client = monitoring_v3.MetricServiceClient()
    now = int(time.time())
    for name, value in metrics.items():
        series = monitoring_v3.TimeSeries()
        series.metric.type = f"custom.googleapis.com/sms_spam/{name}"
        series.resource.type = "global"
        series.points = [monitoring_v3.Point({
            "interval": {"end_time": {"seconds": now}},
            "value": {"double_value": value},
        })]
        client.create_time_series(name=f"projects/{PROJECT}", time_series=[series])
        print(f"pushed custom.googleapis.com/sms_spam/{name} = {value:.4f}")
```

**PSI** (Population Stability Index) measures how far the live score distribution has moved from the baseline histogram. Rule of thumb: below 0.1 stable, 0.1–0.25 a moderate shift, above 0.25 a large shift.

- **Is the model broken, or did the world change?** The share of unsure scores stayed tiny (2%). The model is still confidently separating spam from ham; the **input** moved, not the model's skill. `gcloud` uploads your folder to Cloud Build. **If there is no `.gcloudignore`, it uses `.gitignore`**, which excludes `model/`, and the image would be built without the model. This file controls the upload instead:

```text
.venv/
__pycache__/
.pytest_cache/
tests/
live.csv
```

Cloud Run runs as the project's default compute service account. Let it call Gemini:

```bash
PROJECT_NUMBER=$(gcloud projects describe your-gcp-project-id --format="value(projectNumber)")
gcloud projects add-iam-policy-binding your-gcp-project-id \
    --member="serviceAccount:$PROJECT_NUMBER-compute@developer.gserviceaccount.com" \
    --role="roles/aiplatform.user"
```

Build and deploy in one command (Cloud Build builds the Dockerfile for you, so Docker does not have to run on your laptop):

```bash
gcloud run deploy sms-spam \
    --source . \
    --region us-central1 \
    --memory 1Gi \
    --allow-unauthenticated \
    --set-env-vars USE_LLM=1,GOOGLE_CLOUD_PROJECT=your-gcp-project-id,GOOGLE_CLOUD_REGION=us-central1
```

The first deploy takes a few minutes and ends with:

```text
Service URL: https://sms-spam-xxxxxxxxxx-uc.a.run.app
```

`--allow-unauthenticated` makes the URL public, which is fine for a lab. A real service would require authentication.

## Step 11: Monitor the live service

Send the same campaign to Cloud Run and push the metrics:

```bash
export SERVICE_URL=https://sms-spam-xxxxxxxxxx-uc.a.run.app
python -m src.traffic $SERVICE_URL
python -m src.monitor --push
```

This time the report shows real LLM calls (`LLM called for 24` or a few more, counting ambiguous scores), an `LLM p95` far above the classifier's, and network time in every request. The `--push` lines end with:

```text
pushed custom.googleapis.com/sms_spam/llm_error_rate = ...
```

Where to look in the console:

| Place | What you see |
| --- | --- |
| **Cloud Run → sms-spam → Metrics** | Request count, latency percentiles, instance count, built in |
| **Logging → Logs Explorer**, filter `jsonPayload.message="classify"` | One record per request; try `jsonPayload.llm_status!="ok" AND jsonPayload.llm_status!="skipped"` to find LLM failures |
| **Monitoring → Metrics Explorer**, search `sms_spam` | The six custom metrics from `monitor.py` |
| **Monitoring → Alerting → Create policy** | Alert on `sms_spam/llm_error_rate > 0.05` or `sms_spam/score_psi > 0.25` |

If `--push` fails with `400 One or more TimeSeries could not be written`, you pushed the same metric twice within a few seconds. Cloud Monitoring needs at least 5 seconds between points of one series. Wait and run it again.

### The LLM failure worth rehearsing: quota

Sending 200 requests as fast as possible can hit Gemini's **per-minute** quota. The service keeps answering (status 200, verdict intact, template explanation), and the log records `llm_status` as the error class. In the report it shows up as a non-zero `llm_error_rate`. The four LLM failures look alike from the caller's side but have different fixes:

| What you see | Meaning | Fix |
| --- | --- | --- |
| `429 RESOURCE_EXHAUSTED` | Rate limited, not broken | Throttle and retry with backoff; call the LLM less often |
| `403 PERMISSION_DENIED` | Service account lacks `roles/aiplatform.user` | Grant the role (Step 10); retrying never helps |
| `404 ... model ... not found` | That model name is not served in your region | Check Model Garden; set `LLM_MODEL` |
| `llm_status: "empty"` | A safety filter blocked the input; no error raised | Expected for some spam; the fallback covers it |

## Step 12: Clean up

Cloud Run with no traffic costs almost nothing, and Gemini is billed per token, so nothing large keeps billing. To remove everything:

```bash
gcloud run services delete sms-spam --region us-central1 --quiet
gcloud artifacts repositories delete cloud-run-source-deploy --location us-central1 --quiet
```

The second line removes the images Cloud Build stored. Custom metrics cost almost nothing and expire on their own.

## Common errors and fixes

| Error | Cause | Fix |
| --- | --- | --- |
| `DatasetNotFoundError ... not available for import` | Tried `fetch_ucirepo(id=228)` | Use `src/data.py`, which downloads the ZIP |
| `FileNotFoundError: model/spam.joblib` | Not trained, or started from another folder | `python -m src.train`; run from the project root |
| Cloud Run: `FileNotFoundError: model/spam.joblib` | No `.gcloudignore`, so `.gitignore` excluded `model/` | Add `.gcloudignore` as in Step 10, redeploy |
| `llm_status: "disabled"` on Cloud Run | `USE_LLM=1` not set | Redeploy with `--set-env-vars USE_LLM=1,...` |
| `llm_status: "PermissionDenied"` / `ClientError` | Missing role, wrong project, or wrong model name | Check the log line's error and the table in Step 11 |
| `DefaultCredentialsError` locally with `USE_LLM=1` | No application-default login | `gcloud auth application-default login` |
| Container fails to start on Cloud Run | Not listening on `$PORT` | Keep `--port ${PORT:-8080}` in the Dockerfile `CMD` |
| `400 ... TimeSeries could not be written` | Two points too close together | Wait at least 5 seconds between pushes |
